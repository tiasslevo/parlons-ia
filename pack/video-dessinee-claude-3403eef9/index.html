Guide express : ta vidéo dessinée avec Claude

Claude fabrique avec toi une vidéo où une main dessine chaque idée au moment où la voix la dit. Le dessin : contour noir épais, formes rondes façon dessin animé, couleurs franches. Il se construit en une grande fresque : la caméra zoome sur chaque partie pendant qu'on en parle, puis montre le tout.

Ce qu'il te faut

  • Claude (abonnement Pro recommandé) avec l'exécution de code activée : Paramètres → Capacités → « Exécution de code et création de fichiers ».
  • ChatGPT (ou un autre générateur d'images) pour les dessins : Claude te donne les prompts.
  • Pour la voix, au choix : ElevenLabs relié à Claude (Paramètres → Connecteurs), ta voix enregistrée, ou pas de voix.

1. Installer le skill (5 min, une seule fois)

  1. Télécharge video-dessinee.zip. Ne le décompresse pas.
  2. Dans Claude : Personnaliser → Skills, +, Importer un skill, choisis le ZIP. Vérifie qu'il est activé.
  3. Crée un Projet : Projets → Nouveau projet → le nom de ta chaîne.

Claude Code : décompresse le ZIP dans ~/.claude/skills/video-dessinee/.

Ta voix

  • Voix IA (le plus simple) : dans Claude, Paramètres → Connecteurs → ElevenLabs → Connecter, avec ton compte ElevenLabs. Claude choisit ou te fait écouter des voix.
  • Ta propre voix, partout : sur elevenlabs.io, Voices → Add a new voice → Instant Voice Clone, enregistre 1 à 2 minutes de ta voix au calme. Ensuite, dis à Claude : « Utilise ma voix clonée [nom] ».
  • Ta voix enregistrée librement, sans script : utilise l'app Claude sur ordinateur (Claude Code ou le mode qui travaille sur tes fichiers). Claude installe Whisper sur ton PC, transcrit ce que tu dis et cale tout sur tes vrais mots. Sur le site ou le téléphone, ça ne marche pas : clone plutôt ta voix.

2. Ta première vidéo

Dans ton Projet, nouvelle conversation, colle :

Utilise le skill video-dessinee. Je veux une vidéo dessinée sur : [ton sujet].
Ma vision : [décris-la avec tes mots : ce qu'on doit retenir, le ton, les personnages ou objets
à montrer. Ou écris « propose-moi »].
Durée : [30 s, 1 min…]. Voix : [voix IA (décris-la), ma voix, ou sans voix].

Puis : réponds aux questions → valide le script et le plan des dessins → colle les prompts dans ChatGPT et renvoie les images à Claude (s'il y en a) → valide la voix → regarde la planche et dis « ok » → reçois ta vidéo.

3. Ton kit de style

À la fin, Claude te donne kit-<ton-nom>.zip (style, couleurs, main, voix, ce qui t'a plu). Garde-le. Décompresse-le et ajoute dans les fichiers de ton Projet : style.md, apercu.jpg et les images des dossiers main/ et dessins/.

4. Les vidéos suivantes

Dans ton Projet, colle :

Nouvelle vidéo dessinée sur : [sujet]. Garde mon style. [Affichage : le même, ou propose-moi.]

Hors Projet : joins le ZIP du kit avec ce message.

Si ça cloche

Problème Écris à Claude
Le dessin arrive avant ou après le mot « À 0:12, le dessin doit commencer sur le mot … »
La main va trop vite « Ralentis la main, simplifie ce dessin. »
Un dessin est trop chargé « Simplifie ce dessin : un personnage, deux objets. »
Tu veux un autre rendu « Fais-la au feutre fin / à la craie / un dessin par page. »
Le texte est trop long « Garde seulement : … »
Un dessin ne ressemble pas aux autres « Donne-moi un nouveau prompt dans le même style. »
Vidéo trop lourde pour le téléphone « Sors-la en qualité légère. »

Publie avec la légende donnée par Claude. Voix IA : active « contenu généré par IA ».
