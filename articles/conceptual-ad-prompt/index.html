Conceptual Ad Prompt Kit

Une méthode pour créer des affiches IA avec une vraie idée publicitaire, un système typographique solide et une composition lisible.

Le vrai problème

Quand tu demandes à une IA de faire une belle affiche, elle peut te sortir un rendu propre. Mais souvent, il manque l'essentiel : une idée.

1

Pas juste une image

Une bonne affiche doit faire passer une idée avant même qu'on lise le texte.

2

Une vérité humaine

Le prompt doit chercher ce que le produit change vraiment dans la vie de quelqu'un.

3

Une métaphore

Le produit doit créer, bloquer, révéler, remplacer ou transformer quelque chose dans l'image.

La méthode

Le moteur repose sur une chaîne simple : produit, vérité humaine, métaphore physique, direction typographique, composition texte, prompt final.

Produit Vérité humaine Métaphore Typographie Composition Prompt final
Le prompt ne sert pas seulement à décrire l'image. Il sert à forcer l'IA à penser comme un directeur créatif avant de générer : idée, typo, hiérarchie, placement et lisibilité.

Le prompt assistant

Le workflow en 2 temps

Le meilleur résultat vient rarement d'un prompt unique. Sépare la réflexion créative de la génération d'image.

1

Prompt architect

Une IA texte analyse le produit, cherche des références typo si elle a le web, puis choisit un vrai système visuel.

2

Prompt image

Le prompt final contient l'idée, la scène, la composition, les fonts d'inspiration et le placement du texte.

3

Finition

Si l'affiche contient beaucoup d'infos, génère le visuel puis ajoute le texte exact dans Canva, Figma ou un éditeur.

Le master prompt image

Une fois l'idée et la typo choisies, utilise ce moteur pour générer l'affiche. Il garde la logique créative, la composition et les règles de lisibilité.

Master prompt image
La base à coller dans GPT Image, Gemini ou un autre moteur image

3 modes d'affiches

Le même moteur peut servir à trois formats. Le niveau de texte change, donc la composition typographique doit changer aussi.

A

Conceptual Ad

Très peu de texte. Une idée forte, une punchline courte, un rendu campagne.

B

Promotional Poster

Titre, sous-titre, offre, CTA et infos utiles, avec une hiérarchie typographique claire.

C

Text-heavy

Pour beaucoup d'infos, génère le visuel et les zones de texte, puis ajoute le texte manuellement.

Le texte n'est pas obligé d'être un footer

Les informations utiles doivent être composées comme un élément de design, pas ajoutées timidement en petit en bas.

Marge éditoriale

Pour une affiche luxe, skincare ou mode : petites infos alignées en marge, comme un détail de magazine.

Cartouche utile

Pour un business local : offre, lieu, WhatsApp ou date dans un cartouche propre, pas un footer par défaut.

Micro-système

Pour sport, tech ou food : specs, prix, CTA et infos rangés dans une petite grille typographique.

À retenir

Commence par l'idée, pas par le rendu. Si ton affiche ne dit rien avant le texte, le prompt doit d'abord travailler la métaphore.
